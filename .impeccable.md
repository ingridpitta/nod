# Contexto de design — nod

## Público

Quem usa o nod no dia a dia, num time pequeno. Não há onboarding de estranho: quem abre o
nod já sabe o que é um agente. Uso diário e prolongado — a interface é lugar de trabalho, não vitrine.

## O que a pessoa está fazendo

Delegando tarefas a assistentes de IA e **decidindo** o que eles preparam. A tela é um escritório: a
pessoa é a chefe, os agentes rascunham, e um cartório registra quem decidiu o quê. O trabalho real
acontece na máquina dela; o nod organiza e guarda o registro.

## Tom

**Discreto e factual.** Registrar sem drama, como quem anota. A interface não comemora, não se
desculpa e não usa cor de alerta para chamar atenção. Quem relata um problema está contribuindo com
um dado, não reclamando — o texto trata assim.

Corolários: nada de "Ops!", nada de ícone grande acima de título, nada de confirmação eufórica.
Silêncio nunca significa vazio (ADR-029): todo estado fechado aparece escrito, com o motivo.

## Sistema visual (já existe — `web/estilos.css`, não reinventar)

- **Tinta em quatro níveis**: `--ink` #11131a → `--ink-2` #394150 → `--ink-3` #7b8393 → `--ink-4`
  #b4b7bd. Hierarquia é feita com tinta, não com peso nem tamanho.
- **Superfícies**: `--bg` #f7f7f8, `--panel` #fff, `--panel-soft` #f3f4f6; linhas `--line` #ececf0 e
  `--line-2` #d7dbe2.
- **Cor tem semântica fixa**: `--blue` #1f67c6 = ação da pessoa · `--amber` #b4690e = aviso/atenção ·
  `--red` #b42318 = destrutivo · `--ok` #15803d = confirmado. Cor nunca é decoração.
- **Sem gradiente, sem glassmorphism, sem sombra colorida.** A única sombra é `--shadow`, neutra.
- **Raio generoso** (10–24px) — o sistema é arredondado e calmo, não anguloso.
- **Ícones**: SVG inline 24×24, `stroke-width` 1.6, `currentColor`, `fill="none"`. Não há biblioteca
  de ícones; os paths são desenhados à mão no estilo Lucide/Feather.

## Restrições técnicas (travadas, ver AGENTS.md)

- Vanilla TypeScript ESM. **Zero dependências de front** — não existe React, nem Tailwind, nem
  biblioteca de ícones. HTML é template string; CSS é arquivo global.
- A web só faz `import type` de `src/` e nunca executa nada do servidor.
- Identificadores, textos e comentários **em português**.
- Comentário registra medição datada (`definido em AAAA-MM-DD: <critério>`), nunca intenção.
- Erro nunca ecoa `err.message`: a web renderiza o código fechado (ADR-002).

## O que torna o nod distinto

O **registro honesto**. Cada mensagem carrega quem a escreveu, sob qual procuração, com qual motor e
a que custo — e isso aparece na interface como dado tipado (as `tag`s de executor, "não confiável",
"parcial"), nunca como prosa inventada. A interface tem a textura de um cartório: sóbria, datada,
verificável. É isso que ela deve continuar parecendo.
